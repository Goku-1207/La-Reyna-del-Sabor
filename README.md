# 👑 La Reyna del Sabor — Mini App

App de pedidos interactiva para **La Reyna del Sabor**.

## 🚀 Características

- ✅ Bienvenida personalizada con nombre del cliente
- ✅ Menú completo con filtros por categoría
- ✅ Fotos reales de cada platillo
- ✅ Modal detalle con variantes (sabores)
- ✅ Carrito de compras interactivo
- ✅ Proceso de pago (Efectivo / Transferencia / Tarjeta)
- ✅ Confirmación de pedido con número único
- ✅ Diseño responsive (móvil y escritorio)
- ✅ Postres ampliados: Churros, Waffles, Brownies, Helado artesanal

## 🌐 Subir a GitHub Pages

1. Crea un repositorio en GitHub: `la-reyna-del-sabor`
2. Sube todos los archivos
3. Ve a **Settings → Pages**
4. En *Source*, selecciona `main` y `/root`
5. Tu app estará en: `https://tu-usuario.github.io/la-reyna-del-sabor/`
